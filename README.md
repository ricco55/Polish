# Polish

A small Python tool that rewrites casual sentences into professionally written ones.

## What you need

- Python
- Ollama
- The qwen3.5:4b model: `ollama pull qwen3.5:4b`
- The Ollama Python package: `pip install ollama`

## How to use it

1. Run `polish.py`
2. Type your message
3. The tool prints a professional version of your message using AI that runs on your own computer.
## Example

Input: `yo boss im late cuz of the train sry`

Output: I apologize for my tardiness as I encountered delays on the train and will be arriving shortly.
